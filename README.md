# 👑 CHAOS: Demon King Base v1.0

> *A Streamlit-powered LLM interface infused with sarcasm, doom, and dark data rituals.*

## 💀 What is CHAOS?

CHAOS is an experimental UI built with [Streamlit](https://streamlit.io/) and powered by a local LLM model (via Ollama). It responds with flair, drama, and just the right amount of villainy. Perfect for:
- 👻 Summoning knowledge with unhinged commentary
- 📚 Generating academic content with flair
- 📊 Uploading files and visualizing them (blood not required)
- 🧙‍♂️ Chatting with a demon because why not

## ✨ Features

- 🔮 Multiple Modes:
  - **Tutor Mode**: Ask educational questions, get sarcastic lectures.
  - **Thesis Generator**: Creates over-the-top academic outlines.
  - **Data Visualization**: Upload CSV/Excel, summon cursed graphs.
  - **Summon CHAOS**: Chat directly with the Demon King.

- 🎭 Themed UI:
  - Gothic background image
  - Glowing boxes of doom
  - Red and purple hues to keep things extra cursed

- 🦴 Backend LLM via `ollama` and `llama3` running locally

## 🧰 Tech Stack

- [Streamlit](https://streamlit.io/)
- [Ollama](https://ollama.ai/)
- [LLaMA3 model](https://ollama.com/library/llama3)
- Python (obviously)
- Sarcasm (in heavy use)
